# lidongjun.com

个人博客：<https://lidongjun.com>

「Keep Climbing. Keep Thinking. Keep Loving.」的个人工坊，横跨技术、学业、职业与生活。目前包含：

- **技术栈 · Tech Map** — 已内化的技术与知识，按学科 / 主题成体系沉淀：数学、人工智能、计算机基础、编程语言、软件工程、外语，以及高中知识（语文 / 英语 / 数学 / 物理 / 化学 / 生物与高考强基，源自家教讲义）。
- **学业 · Academics** — 学校相关：按年级 / 学期归档的课程笔记与应试复习（目前已整理大一、大二的非水课及大三课程；每门课按速成、真题、知识点与作业组织），真题与作业的答案或提交内容默认折叠、可手动展开；竞赛（CSP、数学竞赛、数学建模、冯如杯、挑战杯的准备材料与流程），科研（WIP），以及学生工作（助教注意事项；社会实践 WIP）。
- **事业 · Career** — 实习、求职与职场思考，目前收录 2025 年末至 2026 年初的实习面经、2026 年秋招面经，以及家教简历。
- **生活 · Love & Interests** — 生活、爱好与情感随笔，目前收录高中班级的大学去向记录。
- **思考 · Thoughts** — 目标、规划、复盘与方法论，目前收录 2025 年终总结、成长目标清单、自我解构与学习经验总结。
- **健康 · Health & Fitness** — 训练、饮食与身体管理（WIP）。

Tags 只使用少量稳定的跨内容主题，不用课程名或零散知识点制造标签云。

每个页面的页脚都显示当前页面访问量、全站总访问量与访客数。

站点用 [Astro](https://astro.build/) 构建，部署于 GitHub Pages。

## 本地预览

需要 Node.js ≥ 22.12 和 pnpm 10.33.0。在包含 `package.json` 的 checkout 目录中运行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

运行 `pnpm build` 生成静态站点，再用 `pnpm preview` 查看构建结果。开发与协作约定见 [AGENTS.md](AGENTS.md)。
