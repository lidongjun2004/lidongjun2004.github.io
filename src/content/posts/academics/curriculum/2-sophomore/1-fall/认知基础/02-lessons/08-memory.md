记忆不是一个被动文件仓库。“记住”至少包括编码、保持和提取；而每次提取都可能依据当前语境重建经验，并在再巩固中改变它。

## 记忆系统不是只按“保存时间”分类

```text
外界输入
  → 感觉记忆：大容量、极短暂
  → 注意选择
  → 短时/工作记忆：暂存并操作当前信息
  ↔ 长时记忆：知识、事件、技能与情感联系
```

这个图是理解分工的起点，不应看成信息只能单向流动的管道。长时知识会影响当前注意和编码，工作记忆也会不断从长时记忆提取信息。

## 感觉记忆：为连续世界保留短暂痕迹

视觉的图像记忆和听觉的声像记忆，能在刺激消失后短暂保留大量细节。只有被注意选中的一部分才会进入更稳定的当前加工。

它的价值是将瞬间输入变成可选择的窗口。如果没有这种短暂保留，眼动、闪烁和连续语音会更难被整合。

## 短时记忆：容量有限，组块取决于已有知识

一串无关字符很难保持，但同样数量的字符若可重组成熟悉缩写，就可以形成更少的“组块”。组块不是输入本身的物理分段，而是依赖长时知识的组织单位。

复述能延长信息保持，但简单机械重复并不总能形成坚固长时记忆。将新信息与已有知识建立意义联系，通常比只重复表面形式有效。

## 工作记忆：暂存 + 控制

课件区分了短时记忆和工作记忆。后者通常包括：

- 语音环路：短暂维持语音/文字顺序；
- 视空画板：维持形状、位置与空间变换；
- 情景缓冲器：将多模态信息和长时知识绑定成暂时情景；
- 中央执行：分配注意、切换任务、抑制干扰并协调子系统。

“中央执行”是功能名称，不是大脑里一个真的小人。一个好的模型还需要说明这些控制如何由可实现机制产生。

## 长时记忆包含多种内容

| 类型 | 例子 | 是否通常可言语报告 |
|---|---|---|
| 情景记忆 | 记得昨天在图书馆与谁说过话 | 是 |
| 语义记忆 | 知道地球绕太阳运动 | 是 |
| 程序性记忆 | 会骑自行车 | 难以完整言语化 |
| 启动/条件作用 | 早先经验改变后续识别或反应 | 常不自知 |

情景与语义记忆常被列为外显记忆，程序技能和启动等常列为内隐记忆。这些系统在脑基础、学习速度和表达方式上不完全相同，因此“记忆好不好”不是一个单维属性。

## 遗忘不只是痕迹自然消失

遗忘可以来自：

- 编码时就没有处理关键信息；
- 新旧记忆互相干扰；
- 提取线索与编码时语境不匹配；
- 记忆表征在再巩固中被改写；
- 存储痕迹随时间减弱。

“当下想不起来”不等于信息已完全丢失。合适的地点、味道、词首或问题表述可能使记忆恢复，这说明提取是一个线索依赖过程。

## 互补学习系统：快速经验存储与缓慢统计学习

如果系统每学一个新事件就大幅改写已有知识，会产生灾难性忘却；如果只缓慢积累统计，又难以一次记住某个独特经历。

互补学习系统用两种时标分工解释这个矛盾：海马体相关系统快速编码情景联系，新皮层相关系统通过重放和重复暴露缓慢整合统计结构。睡眠中的重激活被认为可能参与这种巩固。

## 层次时序记忆：用可预测的序列建立层次表征

课件介绍的层次时序记忆试图用皮层启发的稀疏分布表征和序列记忆来学习时间模式。低层学局部、快速变化，高层将低层序列压成更稳定的结构，并依据上下文预测下一个输入。

它展示了一种把记忆与预测绑在一起的计算观点。但这是某种认知建模方案，不能因为它使用“皮层启发”就把其所有部件当成已被神经实验证实。

## 学习时使用记忆规律

- 分散练习通常比一次长时间堆积更利于长期保持；
- 主动提取比只重读更能检验和强化可用记忆；
- 将新概念与已有结构联系，比孤立复述更有利于线索丰富的编码；
- 交错练习会增加当下难度，但能迫使学习者识别应该选哪种方法；
- 熟悉感不是牢固记忆的同义词，应用闭卷回忆和新题迁移检查。
