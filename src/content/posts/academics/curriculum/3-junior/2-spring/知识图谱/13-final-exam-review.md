## 3. 计算练习

### 3.1 Dice / Jaccard 系数

**公式**：

$$
\text{Dice}(S, T) = \frac{2|S \cap T|}{|S| + |T|}, \quad \text{Jaccard}(S, T) = \frac{|S \cap T|}{|S \cup T|}
$$

**例题**：`Lvensshtain` vs `Levenshtein`

1. 转 bigram：
   - S = {Lv, ve, en, ns, ss, sh, ht, ta, ai, in} (10 个)
   - T = {Le, ev, ve, en, ns, sh, ht, te, ei, in} (10 个)
2. 交集：`{ve, en, ns, sh, ht, in}`，$|S \cap T| = 6$
3. **Dice** = $2 \times 6 / (10 + 10) = 0.6$
4. 并集 14 个 → **Jaccard** = $6 / 14 \approx 0.429$

### 3.2 TF-IDF + 余弦相似度

课件给出的 8 个步骤：
1. 分词 → 2. 列所有词 → 3. 算 TF → 4. 算 IDF → 5. 算 TF-IDF
→ 6. 选 Top-N 关键词 → 7. 构词频向量 → 8. 余弦相似度

公式：

$$
\text{TF}(t, D_i) = \frac{\text{词 } t \text{ 在文档 } D_i \text{ 中出现次数}}{\text{文档 } D_i \text{ 总词数}}
$$
$$
\text{IDF}(t) = \log \frac{N}{|\{i : t \in D_i\}|}
$$
$$
\text{cos}\theta = \frac{\vec{A} \cdot \vec{B}}{|\vec{A}||\vec{B}|}
$$

### 3.3 TransE 损失函数

$$
L = \sum_{(h, r, t) \in T} \sum_{(h', r, t') \in T'} \max(0, \gamma + E(h, r, t) - E(h', r, t'))
$$

- $T$ = 正样本，$T'$ = 负样本，$\gamma$ = margin

### 3.4 KGE 评价指标

$$
\text{MR} = \frac{1}{N} \sum_i \text{rank}_i
$$
$$
\text{MRR} = \frac{1}{N} \sum_i \frac{1}{\text{rank}_i}
$$
$$
\text{Hits@n} = \frac{1}{N} \sum_i \mathbb{I}(\text{rank}_i \le n)
$$

### 3.5 RDF 直接映射 IRI 生成

- 主语 IRI = 前缀 + 表名 + 主键列名 + 主键值
- 谓词 IRI = 前缀 + 表名 + 列名
- 外键 IRI = 前缀 + 引用表名 + 引用列名

## 4. 简答题的组织方式

### 4.1 解释 X 是怎么做的

> **X 的定义 + 关键步骤 + 优缺点 + 应用场景**

例题："请解释知识图谱嵌入（KGE）的概念和主要方法"

参考答案结构：
1. **定义**：把 KG 嵌入到低维向量空间
2. **动机**：解决计算效率 + 数据稀疏
3. **4 大类方法**：翻译、张量分解、神经网络、图神经网络
4. **代表模型**：TransE（详细打分函数）
5. **评价指标**：MR / MRR / Hits@n
6. **优缺点**：效率高 vs 不可解释

### 4.2 对比 A 和 B

> **A 的定义 → B 的定义 → A vs B 表格 → 总结建议**

例题："请对比 RDF 和属性图"

| 维度 | RDF | 属性图 |
|---|---|---|
| 起源 | 语义网 | 数据库 |
| 属性表达 | 用额外三元组表达 | 节点、边原生携带键值属性 |
| 查询 | SPARQL | Cypher |
| ... | ... | ... |

### 4.3 分析问题并给出方案

> **问题描述 → 原因分析 → 解决方案 → 具体方法**

例题："多源知识图谱融合中遇到实体歧义如何解决？"
答：
1. **歧义类型**：多义（同名不同实体）、同义（不同名同实体）
2. **解决思路**：先生成候选匹配对，再结合名称、上下文和图结构判断是否同一实体
3. **方法**：VMI 用倒排索引分块；AMiner 经度量学习和图编码后聚类，完成同名作者消歧
4. **跨图案例**：OAG 的 LinKG 分别匹配出版地点、论文和作者，对齐 Microsoft Academic Graph 与 AMiner

## 5. 答题安排建议

### 5.1 答题顺序

| 题型 | 先检查什么 |
|---|---|
| 选择题 | 概念层级、术语边界和模型归属 |
| 计算题 | 公式、集合或向量口径、代入过程 |
| 简答题 | 定义、步骤、优缺点和适用场景 |
| 综合题 | 先拆任务，再选择抽取、融合、存储或推理方法 |

### 5.2 答题原则

1. **定义先行**：先说明所讨论的对象，避免后文术语指代不清
2. **要点 + 例子**：列出关键步骤，再用 1-2 个例子说明
3. **对比表格**：维度较多时用表格对齐同一组比较标准
4. **公式 + 推导**：计算题先写公式再代数字
5. **术语准确**：使用“三元组”“SPARQL”“TransE”等明确术语，不用含混的近义说法

### 5.3 细节想不起来时

- **如果忘了模型细节**：先写定义和基本思路，再补充能确认的步骤
- **如果知识点比较陌生**：从问题中的任务目标出发，说明输入、处理过程和输出，不编造模型名或公式
- **如果时间不够**：先完成有把握的部分，再回头补不确定的题
