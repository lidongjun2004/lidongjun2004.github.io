## 程序设计学习心得

这学期进行了程序设计的学习，也是我第一次接触 C 语言。

我先前在初中参加过 NOIP 竞赛，有一定的基础，获得过普及组一等奖和提高组二等奖。只不过那时使用的是 C++。C 语言与 C++ 有很多很多相同之处，但也有一些地方远没有 C++ 智能。C++ 的数据库当中有很多很多即插即用的函数。比如比 C 语言的 `qsort` 快捷很多的 `sort` 函数，尽管 `sort` 的 `cmp` 适用范围并不是很广。再比如 `max`、`min`、`swap`、`fabs` 等等基础功能的函数。而且 C 语言只能使用比较复杂的 `scanf` 和 `printf`，而不能使用短小的 `cin` 和 `cout`。

以上这些都让我在学习的一开始感到有些头疼。但是在学习的过程中，我学习到了很多。比如 C 语言编译的底层逻辑，对一些边界情况和极端情况有了更多的了解，对一些函数的运用也更为深刻。C 语言能够更好锻炼我的代码能力，一些本来直接调用数据库就可以使用的函数都需要手搓出来，这让我更深刻了解了函数背后的思路。因此对我的算法能力提升贡献颇多。

学习程序设计也让我时隔三年重新捡起了信息竞赛这个久违的事情，弥补了我高中选择课内放弃竞赛的决定。也让我重新燃起了对编程和算法的思考和热爱。因为热爱，也才让我选择了这个专业。因此，我在未来的大学生涯中也会继续热爱它。
